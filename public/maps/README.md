# Map artwork

The continent maps are the WoW Forever world maps, copyrighted to Blizzard Entertainment.
If an image is missing, the app shows a schematic map instead.

| File | Source |
|---|---|
| `kalimdor.jpg` | https://warcraft.wiki.gg/wiki/File:WorldMap-Kalimdor_c60.jpg |
| `eastern-kingdoms.jpg` | https://warcraft.wiki.gg/wiki/File:WorldMap-EasternKingdoms_c60.jpg |

Both images are 1002 x 668 pixels. Zone marker positions in `src/data/mapArt.ts` assume that size.
